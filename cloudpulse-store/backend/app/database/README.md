# `app/database/` — Persistence layer

SQLAlchemy 2 setup for the SQLite database (swappable through `DATABASE_URL`).

| File | Responsibility |
|---|---|
| `connection.py` | Builds the engine from `settings.database_url`, defines `Base`, `get_db()` (one session per request), `init_db()` (create tables) and `check_db_connection()` (used by `/api/ready`) |
| `models.py` | ORM tables `products`, `orders`, `order_items`, `contact_messages`, with check constraints and a `UTCDateTime` type that always returns timezone-aware UTC timestamps |
| `seed.py` | 24 fictional demo products in 6 categories; inserted only when the products table is empty |

Database location: `/app/data/cloudpulse.db` on the Docker volume `sqlite_data`, or
`backend/data/cloudpulse.db` when run without Docker. Database files are ignored by Git.

The product slugs in `seed.py` must match the SVG images generated by
[`frontend/scripts/generate-product-images.mjs`](../../../frontend/scripts/README.md).
