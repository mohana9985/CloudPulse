# API Documentation

Base URL: `http://localhost/api` (Docker) or `http://<EC2-public-IP>/api`.

Interactive documentation (generated by FastAPI, always up to date):

* Swagger UI: <http://localhost/api/docs>
* ReDoc: <http://localhost/api/redoc>
* OpenAPI JSON: <http://localhost/api/openapi.json>

All request and response bodies are JSON (except `/api/metrics`). Prices are in INR.
There is no authentication; this is a demonstration store.

## Summary

| Method | Path | Description | Success |
|---|---|---|---|
| GET | `/api/health` | Liveness | 200 |
| GET | `/api/ready` | Readiness (database check) | 200 / 503 |
| GET | `/api/products` | List products (filter, search, sort, paginate) | 200 |
| GET | `/api/products/search?q=` | Search products | 200 |
| GET | `/api/products/{product_id}` | Product details | 200 / 404 |
| GET | `/api/categories` | Categories with product counts | 200 |
| POST | `/api/orders` | Create demonstration order | 201 / 404 / 409 / 422 |
| GET | `/api/orders` | Recent orders | 200 |
| GET | `/api/orders/{order_id}` | Order details | 200 / 404 |
| POST | `/api/contact` | Submit contact form | 201 / 422 |
| GET | `/api/metrics` | Prometheus metrics (text) | 200 |
| GET | `/api/stats` | Application statistics (JSON) | 200 |

## Error format

```json
{ "detail": "Product 999 not found" }
```

Validation errors (HTTP 422) list each invalid field:

```json
{ "detail": [ { "loc": ["body", "email"], "msg": "value is not a valid email address", "type": "value_error" } ] }
```

| Status | Meaning |
|---|---|
| 400 | Business rule violated |
| 404 | Product or order does not exist |
| 409 | Insufficient stock |
| 422 | Invalid input (missing field, wrong type, too short/long) |
| 503 | Not ready (database unavailable) |

  "checks": { "database": "ok", "products_seeded": "ok" },
  "product_count": 24, "timestamp": "2026-11-04T15:56:28.401000+00:00" }

## Products

### `GET /api/products`

| Query param | Type | Default | Notes |
|---|---|---|---|
| `category` | string | - | Exact category name, e.g. `Books` |
| `q` | string | - | Text filter (name, description, category) |
| `sort` | `name` \| `price_asc` \| `price_desc` \| `newest` | `name` | |
| `page` | int >= 1 | 1 | |
| `page_size` | int 1-100 | 100 | |

```bash
curl "http://localhost/api/products?category=Books&sort=price_asc&page=1&page_size=12"
```

```json
{
  "items": [
    { "id": 12, "name": "Linux Command Line Handbook", "description": "...", "price": 449.0,
      "category": "Books", "image_path": "/products/book-linux-cli.svg",
      "stock_quantity": 300, "in_stock": true, "created_at": "2026-11-04T15:50:00+00:00" }
  ],
  "total": 4, "page": 1, "page_size": 12, "total_pages": 1
}
```

### `GET /api/products/search?q={query}`

`q` is required (1-100 chars); optional `limit` (1-100, default 50). Case-insensitive
match on name, description and category. Returns an array of products.

```bash
curl "http://localhost/api/products/search?q=keyboard"
```

### `GET /api/products/{product_id}`

Returns one product object, or 404 `{"detail": "Product 999 not found"}`.

### `GET /api/categories`

```json
[ { "name": "Books", "product_count": 4 }, { "name": "Electronics", "product_count": 4 } ]
```

## Orders (demonstration only, no payment)

### `POST /api/orders`

| Field | Rules |
|---|---|
| `customer_name` | 2-100 characters |
| `email` | valid email |
| `address` | 5-300 characters |
| `items` | 1-20 items; each `product_id` > 0 and unique, `quantity` 1-20 |

```bash
curl -X POST http://localhost/api/orders -H "Content-Type: application/json" -d '{
  "customer_name": "Demo Customer",
  "email": "demo@example.com",
  "address": "12 Demo Lane, Pilani, Rajasthan",
  "items": [ { "product_id": 1, "quantity": 2 }, { "product_id": 5, "quantity": 1 } ]
}'
```

Response **201**:

```json
{
  "id": 1, "customer_name": "Demo Customer", "email": "demo@example.com",
  "address": "12 Demo Lane, Pilani, Rajasthan",
  "subtotal": 16897.0, "shipping_fee": 0.0, "total_amount": 16897.0,
  "status": "CONFIRMED", "created_at": "2026-11-04T16:00:00+00:00",
  "items": [
    { "id": 1, "product_id": 1, "product_name": "Wireless Noise-Cancelling Headphones",
      "image_path": "/products/wireless-headphones.svg", "quantity": 2,
      "unit_price": 7999.0, "line_total": 15998.0 }
  ]
}
```

Shipping: free when subtotal >= INR 999, otherwise INR 99.
Errors: 404 unknown product, 409 insufficient stock, 422 invalid input.
The order is created in a single transaction: if any item fails, nothing is saved
and no stock is changed.

### `GET /api/orders?limit=20`

`limit` 1-100 (default 20). Newest first.

```json
[ { "id": 3, "customer_name": "Demo Customer", "total_amount": 4499.0,
    "status": "CONFIRMED", "item_count": 1, "created_at": "2026-11-04T16:05:00+00:00" } ]
```

### `GET /api/orders/{order_id}`

Same shape as the `POST /api/orders` response; 404 if not found.

## Monitoring

### `GET /api/metrics`

Prometheus text exposition format, for example:

```
cloudpulse_http_requests_total{endpoint="/api/products/{product_id}",method="GET",status_code="200"} 42.0
cloudpulse_http_request_duration_seconds_bucket{endpoint="/api/products",le="0.01",method="GET"} 37.0
cloudpulse_http_errors_total{endpoint="/api/orders",method="POST",status_code="409"} 2.0
cloudpulse_http_requests_in_progress 1.0
cloudpulse_app_uptime_seconds 3605.2
```

| Metric | Type | Labels |
|---|---|---|
| `cloudpulse_http_requests_total` | Counter | method, endpoint, status_code |
| `cloudpulse_http_request_duration_seconds` | Histogram | method, endpoint |
| `cloudpulse_http_errors_total` | Counter (status >= 400) | method, endpoint, status_code |
| `cloudpulse_http_requests_in_progress` | Gauge | - |
| `cloudpulse_app_uptime_seconds` | Gauge | - |
| `cloudpulse_app_start_time_seconds` | Gauge | - |
| `cloudpulse_orders_created_total` | Counter | - |
| `cloudpulse_contact_messages_total` | Counter | - |
| `cloudpulse_app_info` | Info | version, environment |

`endpoint` is the route template (never a raw ID); unknown URLs are labelled `unmatched`.

Useful PromQL:

```
sum(rate(cloudpulse_http_requests_total[1m]))                                   # requests/s
sum by (endpoint) (rate(cloudpulse_http_requests_total[1m]))                     # per endpoint
histogram_quantile(0.95, sum by (le) (rate(cloudpulse_http_request_duration_seconds_bucket[5m])))  # p95
sum(rate(cloudpulse_http_errors_total[5m])) / sum(rate(cloudpulse_http_requests_total[5m]))       # error ratio
```

### `GET /api/stats`

```json
{ "service": "cloudpulse-store-backend", "version": "1.0.0",
  "total_api_requests": 1532, "total_products": 24, "total_orders": 51,
  "total_contact_messages": 2, "uptime_seconds": 3605.2,
  "started_at": "2026-11-04T15:00:00+00:00", "timestamp": "2026-11-04T16:00:05+00:00" }
```

`total_api_requests` counts requests since the backend process started (resets on restart);
the other totals come from the database. No configuration or secrets are exposed.
