# results/live-mac-20261112

REAL-execution results of the live cluster on one Docker host (Mac, Colima), 12 Nov 2026: grid (45 runs), normal vs failure (30 runs) and scaling (1/2/3 workers). `runs_*.csv` = one row per run, `tasks_*.csv` = one row per task, `per_worker_*.csv` = per-worker counts and resources, `events_*.jsonl` = coordinator events, `*_summary.csv` = aggregated tables, `metadata*.json` = settings and environment. Discussed in [`docs/live_results.md`](../../docs/live_results.md); the run log is [`../live-mac-20261112.log`](../live-mac-20261112.log).
